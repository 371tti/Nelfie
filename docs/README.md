# 開発者向けドキュメント

README はセットアップ、設定、Discord コマンドなどの利用者向け案内です。コードの構成と変更時の手順は以下を参照してください。

- [アーキテクチャ](architecture.md): 起動順、モジュール、状態の所有者、主要な処理経路
- [AIチャットの処理フロー](chat-flow.md): Discord発言から応答・履歴圧縮までの順序
- [開発手順](development.md): ローカル実行、静的チェック、変更時の入口、監視サーバー
- [タイムアウト方針](timeouts.md): 処理ごとの期限、期限切れ時の動作、外部通信上限
- [VOICEVOX 処理](voicevox.md): core 初期化、音声合成キュー、読み上げ再生

動作の詳細はソースコードを正とします。環境変数と Discord コマンドの一覧はリポジトリ直下の [README.md](../README.md) を参照してください。
